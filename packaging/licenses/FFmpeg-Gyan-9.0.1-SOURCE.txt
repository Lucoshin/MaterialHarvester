FFmpeg / ffprobe corresponding-source information
=================================================

Distributed binaries
--------------------
Material Harvester redistributes ffmpeg.exe and ffprobe.exe from the official
Gyan FFmpeg 9.0.1 essentials static Windows build. The build is licensed under
GNU GPL version 3. The complete license text and the build's original README
are included next to this notice.

Binary build archive:
https://www.gyan.dev/ffmpeg/builds/packages/ffmpeg-9.0.1-essentials_build.zip

Archive SHA-256 calculated after HTTPS download:
